# Titanic Survival EDA

## Overview
Exploratory Data Analysis on the Titanic dataset to uncover 
survival patterns across gender, class, and age.

## Key Findings
- Only 38% of passengers survived
- Women were 4x more likely to survive than men (74% vs 19%)
- 1st class passengers had 2.6x higher survival rate than 3rd class

## Tools Used
Python · Pandas · Matplotlib · Seaborn

## Dataset
Built-in Titanic dataset via Seaborn library
